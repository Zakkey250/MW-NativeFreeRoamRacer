# NFSMW Limit Breaker 同梱版

**0.1.3-resource-headroom.2** をNFRR 0.1.2に同梱。レーサー・警察と一般交通の共存を助ける任意の付属MODです。LBを外してもNFRRは動作します。

## 導入と車両枠

ゲーム終了中にASIとINIを `scripts` へ配置。更新時は既存INIを保管し、新項目を追記してください。資源設定の変更後は完全再起動が必要です。

論理上限は20・24・28・32台、既定32台。格納領域はガード付き64枠です。全ての描画・イベント・音声・他MODの生成処理が32台対応になるという意味ではありません。

## 新しい車両資源設定

```ini
[VehicleResources]
AdditionalSkins = 1
PartModelSlots = 4096
```

Unlimiterがない環境では `AdditionalSkins=1` により導入済みテクスチャから追加スキン・ホイール・スピナー8セットをメモリ内に準備します。純正の書換用1～4、事前合成用5～12、専用追加13～20は別枠です。ゲームの銀行ファイルを置換しません。未知の形式は安全に拒否します。独立合成可能な車両が16台になるという意味ではありません。

NFSMWUnlimiterが読み込み済み、または導入先に存在する場合、LB独自のスキン割当は設置しません。Unlimiterの割当・解放処理と設定を維持してください。`CarSkinCount` は実際のDUMMY_SKIN・DUMMY_WHEEL・DUMMY_SPINNER資源数に合わせます。LBの32台設定だけを根拠に20・32を指定しないでください。

`PartModelSlots=4096` は改造パーツのeModel枠を純正1024から拡張し、追加予約は72KiBです。1024～4096を設定でき、0で無効化。既にプールが生成済み、未知のパッチ所有者などの場合は設置を拒否し、他MODが予約した大きな領域を縮小しません。Carsのバイト領域やゲーム素材は変更しません。

複数の改造車を扱う資源の余裕を増やしますが、透明化の全原因や全車種・16台の長時間安定性を保証するものではありません。

## 任意の音声枠拡張

```ini
[Audio]
LBEngineAudioExpansion = 0
```

新規既定OFF。従来ONだった設定は保持できます。ONでは独立した8MiBのミキサー領域と能力情報を提供しますが、音声スロット数を単独で増やしません。6枠利用にはNFRR側の対応設定も必要です。NFRRがABI・能力・実割当を検査し、条件不足なら通常制限に戻ります。固定バージョン依存ではありません。

## Event Loader先行対応

任意の生成・イベント側MODとの共存を想定しています。NFRRはイベントAIの所有権も別途調整します。Event Loaderは必須・同梱ではなく、順位表・カットシーン・マップ・ゲーム素材を提供しません。車両・スキン・パーツモデル・音声は独立した制限です。

## 診断とソース

`[Diagnostics] Logging=0` が既定。省略・空欄・不正値もOFFです。正確な `1` を指定し再起動した場合だけ診断が有効になります。OFFでは診断用の整形・ファイル作成・定期監視を省略します。配布用設定に一時的なONを残さないでください。

Visual Studio 2022 C++ v143とWindows SDKでRelease Win32をビルドします。NativeHarnessターゲットでオフライン検査が可能です。連携は人口・予約・資源のV1 APIを取得し、ABI・能力を検査してください。リリース番号の比較で機能を決めないでください。
