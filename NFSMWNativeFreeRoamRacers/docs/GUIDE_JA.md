# MW Native Free Roam Racer

フリーロームにAIレーサーを追加し、追走から1対1のエンカウンターバトルへ移行できるASI MODです。

**alpha.50のアルファ配布版です。開発環境での正常動作を確認済みですが、他の車両・MOD構成は実走未検証です。**

初回はセーフハウスに約2秒滞在してからフリーロームへ進み、車種一覧の構築・生成を待ってください。成功した価格・車種・性能情報は `scripts/NativeFreeRoamRacers/VehicleCatalog.cache.bin` に保存し、次回起動時に関連データのSHA-256が一致すれば再利用します。車種定義やUnlimiter設定の変更・キャッシュ破損時だけ再構築します。ゲームデータの変更は終了中に行ってください。このキャッシュは配布物に含めません。

## 対応環境

- Windows、PC版Need for Speed Most Wanted (2005)、ASIローダー。
- 現ビルドの対象はNFSPatcher English 1.3 + LAAの`speed.exe`、6,029,312バイト、SHA-256 `B248271BF8EAC8C9B283B8C95E3ADD672B713BF529B05F1780E58268493B9D06`です。他のEXEをファイル名だけ変更しても対応しません。ゲーム本体・EXE・ASIローダーは付属しません。
- Microsoft Visual C++ x86ランタイム（ビルドに対応するもの）。
- 車種は読み込み済みの車両データから自動取得します。特定の追加車両パック・固定車種リスト・GLOBALファイルのハッシュ一致は不要です。追加車両データ自体は付属しません。
- 純正の外装パーツ関数、またはUnlimiterが所有する対応フックを使用します。不明なフックや不整合のある車両は拒否します。任意のMOD・破損データへの完全互換を保証するものではありません。バニラ構成・他のUnlimiter構成の実走は未確認です。

## 導入・更新・削除

1. ゲームを終了し、既存の同名ASI・INI・TPKとセーブをバックアップします。
2. 配布ZIPの`scripts`をゲームフォルダーへ展開します。`NFSMWNativeFreeRoamRacers.asi`、`.ini`、`.tpk`の3ファイルが同じ`scripts`内に必要です。
3. 更新時に既存INIを保持する場合は上書きしないでください。旧試作版との同時導入は避けてください。別MODやSave Virtualizerのファイルは削除・置換しません。
4. ゲームを起動してキャリアのフリーロームへ入ります。車両一覧の調査と遠方の交通アンカー待ちのため、生成は即時ではありません。

削除時はゲーム終了後に本MODの3ファイルだけを取り除きます。追加した任意の音声は別管理です。更新はセーブや既存の音声を変更しません。

## 遊び方

- 近くのAIレーサーを追走し、左上に参加可能HUDが出たら、ゲーム内で割り当てた「イベント参加」操作を押します。固定のキーボードキー・十字パッドを要求しません。
- 先頭車両が進む道を選びます。追い抜くとリードが交代し、後続を300m引き離すと決着します。勝利報酬はキャッシュ1,000です。
- 左上ゲージはプレイヤーリードが緑、相手リードが赤。バトル中は他の本MODレーサーのマーカーを一時非表示にします。
- プレイヤー後続で100m以上離れた場合、純正GPSで相手方向を案内します。別の目的地を選択した場合などは他の案内を優先します。
- 既存の巡回警察が本MODレーサーを発見する背景追跡にも対応します。常に追跡が発生するわけではありません。

## 配布既定値

|項目|既定値|
|---|---|
|最大生成台数|6台（設定可能1～15台）|
|生成・管理半径|600m|
|ミニマップ表示半径|200m|
|同時車種数|自車を含む5車種（1～5）|
|フリーローム音声枠|4枠（0～4）|
|生成間隔|5秒|
|交通アンカー距離|INI値350～700m、管理半径の制限で実効350～600m|
|後続AI出力倍率|0～100m: 1.50、100m超～200m: 1.75、200m超～300m: 2.00|

車種は価格・純正性能が近い範囲から選びます。台数と車種数は別の設定です。外見は塗装・ボディ・フード・スポイラーをランダム化し、不正なパーツは再抽選、試行上限後は純正へ戻します。性能チューンはキャリアの解禁範囲を守り、ニトロも解禁済み・車種対応の場合に装備します。出力倍率は速度や最高速の倍率ではありません。

INI変更後はゲームを再起動してください。英語メッセージにする場合は`[Encounter]`へ`Language = en`を追加します。省略時は日本語です。背景警察を止める場合は`[BackgroundPolice]`へ`Enabled = 0`を追加します。

## 任意のバトル音声

ゲーム音声は配布しません。別配布の**NFSU2EncounterAudioExtractor**を使い、所有するNFS Underground 2の`SDATA/sdat.viv`から抽出できます。抽出アプリは別途日英説明書を備えています。

出力された`NativeFreeRoamRacers`フォルダーをMWの`scripts`内へコピーします。配置は`scripts/NativeFreeRoamRacers/encounter/start`、`player_victory`、`player_defeat`です。`speaker**`を含む生成ファイル名は変更しないでください。役者を選び、対応する開始・勝利・敗北音声からランダム再生します。

音声は2D再生で、ゲームのボイス音量に追従します。別の`Setting.ini`は不要です。音声を入れなくてもバトルは利用できます。抽出した音声・ゲームアーカイブを再配布しないでください。

## 制限と不具合報告

純正道路探索を利用するため、複雑な分岐、中央分離帯、障害物で減速・迷走・立ち往生することがあります。車両生成はゲームの資源枠と交通状況に依存し、必ず最大台数になるとは限りません。音声枠を6や15へ拡大する機能は含みません。

自動取得には安全上の上限（pvehicle 8,192レコード、1,024車種）があり、不正データや未対応フックを検出すると処理を止めます。初回カタログ調査は1管理更新につき最大1レコードです。
